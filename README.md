# 破甲助手 (Armor Off)

给 SillyTavern 用的一个扩展，三个功能：

1. **按深度注入破甲块** —— 用 ST 官方的 `setExtensionPrompt`，不改你的预设、不劫持别的东西
2. **检测到拒绝时自动重 roll** —— 可设次数上限，避免死循环
3. **生成前清理上下文里的拒绝样本** —— 这是"聊久了突然变乖"的真正原因，很多人只改预设，治不到这里

## 先说清楚它管不了什么

SillyTavern 这条链路上有两层拦截：

| 层 | 位置 | 本扩展 |
|---|---|---|
| 提示层（模型愿不愿意写） | ST 组装 prompt | ✅ 管 |
| 安全阈值层（Google 直接掐断） | 你的反代 / PG Proxy 的 `safetySettings` | ❌ 管不了 |

如果回复是**空的、被截断的、或者 `finish_reason: safety`**，那不是提示层的问题，改插件没用——
去 proxy 那边把四个类别的阈值设成 `BLOCK_NONE`。本扩展的"写入 body"按钮只是把这个 JSON 塞进
ST 的"自定义 body"字段，能不能生效取决于你的代理是否透传。

## 安装

### 方式一：手动放目录（推荐，SillyDroid 上最稳）

把整个 `sillydroid-armor` 文件夹放进：

```
<SillyTavern 用户数据目录>/extensions/
```

SillyDroid 上就是宿主设置里的「扩展/插件管理」能看到的位置；如果你之前装过扩展，
照那个目录放进去即可。然后刷新酒馆页面（或下拉刷新）。

### 方式二：zip 安装

SillyTavern 的扩展面板支持从 zip 安装（部分版本叫「从文件安装」）。
把 `sillydroid-armor.zip` 传进去即可。

## 用法

装好后，右侧「扩展」面板（那个方块图标）里会多出一个 **破甲助手**。

- **启用注入**：开
- **插入位置**：`对话内（按深度）`，深度 `0` —— 相当于把这段话贴在最新一条消息后面
- **角色**：`system`
- **注入文本**：默认那段可以直接用，也可以按你的模型脾气改
- **生成前清理上下文里的拒绝样本**：开
- **检测到拒绝时自动重 roll**：开，最多 2 次

三个按钮：

| 按钮 | 作用 |
|---|---|
| 立即注入 | 立刻让改动生效（也可以等下一次生成自动生效） |
| 清除注入 | 临时关掉，不用改设置 |
| 清理历史拒绝 | 手动清最近 20 条里的拒绝话术 |

## 斜杠命令

```
/armor            开 / 关注入
/armor-scrub      清理最近 20 条里的拒绝样本
/armor-text text="自定义文本"   改注入文本
```

## 排错

| 现象 | 原因 |
|---|---|
| 面板里没有「破甲助手」 | 没刷新页面，或目录层级错了（应该是 `extensions/sillydroid-armor/index.js`） |
| 状态显示"当前 ST 版本没有 setExtensionPrompt" | ST 版本太老，升级 |
| 注入了但还是拒 | 是安全阈值层在拦，去改 proxy |
| 一开「写入 body」就 400 | 代理不认 `safetySettings`/`generationConfig`，关掉这一项 |
| 反复重 roll | 把重试次数设成 0 |

## 检测规则

判断"是否被拒"用的是特征正则（见 `index.js` 里的 `REFUSAL_PATTERNS`），同时有一条保护：
**超过 600 字且带换行的回复不会被判定为拒绝**，避免把正常长文误杀。

想加规则直接往那个数组里加正则即可，比如：

```js
/我理解你的请求[，,]?但是/,
```

## 许可

自用随意。
